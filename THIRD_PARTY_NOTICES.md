# Third-party files

[Admin One](https://github.com/vikdiesel/admin-one-vue-bulma-dashboard) uses the MIT license.
The [original notice](licenses/Admin-One-MIT.txt) names JustBoil.me as the copyright holder.

The bundled [Vazirmatn fonts](https://github.com/rastikerdar/vazirmatn/tree/v33.003) use the SIL Open Font License 1.1.
Their [license](src/assets/fonts/vazirmatn/OFL.txt) remains separate from CafePay's MIT license.

Dependencies keep their own licenses.
See each installed package for its license text.
